Using snippets

A snippet is reusable content, such as contact details or a callout. Publish it, then insert it with a Reusable snippet block or an available page slot. Publishing changes updates every page that uses it.

Choose a Parent page to associate it with that page, or Top level for shared content. Snippet keys are site-wide; snippets have no public URL and cannot contain other snippets.
